Cómo alojar en GitHub Pages

Publicar esta calculadora en internet de forma **totalmente gratuita** es fácil con GitHub Pages:

  1. Crea un repositorio: Ve a GitHub.com, crea un nuevo repositorio público (ej: mi-calculadora).
  2. Sube el código: Guarda todo este código en un archivo llamado estrictamente index.html y súbelo a la rama principal (main o master).
  3. Activa GitHub Pages:
    • Entra a la pestaña Settings del repositorio.
    • En el menú izquierdo, selecciona Pages.
    • Bajo Build and deployment, selecciona la rama main y guarda.
  4. ¡Listo! En 1 o 2 minutos tu web estará activa en una URL como:
    https://tu-usuario.github.io/mi-calculadora/
